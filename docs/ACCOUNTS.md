## 功能演示流程

### 消费者购物
1. 以 `shike` / `123456` 登录
2. 「发现好物」→ 浏览 30 种福建农产品 → 点击卡片查看详情 → 加入购物车
3. 「购物车」→ 调整数量 → 去结算 → 确认支付 → 生成订单
4. 「我的需求」→ 查看定制需求

### 商家管理
1. 以 `nanping` / `123456` 登录
2. 「工作台」→ 查看经营数据
3. 「商品管理」→ 查看/编辑 4 种南平产品
4. 「订单管理」→ 确认接单 → 发货 → 完成
5. 「我的资质」→ 查看/申请资质

### 审核方审批
1. 以 `fujiangongshang` / `123456` 登录
2. 「审核管理」→ 通过/拒绝待审资质（仅限管辖范围）
3. 「资质管理」→ 收回/续期/恢复资质（触接 ABE 属性撤销）

### 管理员
1. 以 `admin` / `admin123` 登录
2. 「用户管理」→ 查看全部 21 个用户
3. 「规则管理」→ 更新认证规则（触接 ABE 密钥轮换）

### 监管方追溯
1. 以 `shiyaojian` / `123456` 登录
2. 「产品档案查询」→ 搜索产品 → 查看全链路追溯
3. 「应急处理」→ 紧急解密
