# 系统架构全景

## 一、整体架构

```
浏览器 (Vue 3 SPA, 无构建工具)
    │  HTTP JSON
    ▼
Go 后端 (:8080, Gin 框架)
    │
    ├──→ Java ABE 服务 (:8081, JPBC + MAFASAC-AR)
    ├──→ MySQL 8.0 (:3306, Docker)
    └──→ Hyperledger Fabric 2.3 (可选, 追溯链码)
```

五层结构：

| 层 | 技术 | 职责 |
|----|------|------|
| 前端展示 | Vue 3 CDN + 原生 CSS/JS | SPA 应用，39 组件（12基础+27页面） |
| 后端服务 | Go + Gin | 40 条 API 路由，ABE 加解密调度 |
| 数据存储 | MySQL 8.0 (Docker) | 7 张表，持久化所有业务数据 |
| 密码学 | Java 17 + JPBC | MAFASAC-AR 属性基加密 |
| 区块链 | Hyperledger Fabric 2.3 | 产品追溯，密文哈希上链（可选） |

## 三、请求生命周期（以发布加密需求为例）

```mermaid
sequenceDiagram
    participant 浏览器 as 浏览器 (Vue 3)
    participant Go as Go 后端 (:8080)
    participant MySQL as MySQL
    participant Java as Java ABE (:8081)
    participant Fabric as Fabric

    浏览器->>Go: POST /api/custom-order<br/>{title, conditions, consumer_id}
    Go->>Go: ConditionToPolicy(conditions)<br/>→ "(Location=福建, Capability=制茶; 2)"
    Go->>Java: POST /api/encrypt (描述文本)
    Java-->>Go: {id: uuid, status: "encrypted"}
    Go->>MySQL: INSERT custom_orders (含 policy, session_id, ciphertext)
    Go->>Fabric: SubmitToFabric (可选, 密文哈希上链)
    Go-->>浏览器: {status: "success", data: 订单, policy_tip: "..."}
```

## 四、前端架构

### 技术选型

| 项 | 选型 | 原因 |
|----|------|------|
| 框架 | Vue 3 CDN | 零构建，运行时模板编译 |
| 设计 | 自定义 CSS (~900行) | 森林绿 `#2D6A4F` + 暖土中性色 |
| 路由 | `window.navigateTo(pageKey)` | 自定义 hash-free SPA |
| 状态 | `window.App` + `Vue.reactive` | 轻量，无需 Vuex |
| 持久化 | localStorage (会话/购物车) + MySQL (业务数据) | 前端状态本地存，业务数据服务端存 |

### 组件体系（39 个）

```
基础组件 (9): Button, Card, Input, Modal, Badge, Tag, Toast, Loading, Empty
业务组件 (3): ConditionSelector, ProductCard, QualificationTags
页面组件 (27): 按 5 角色分配
  consumer:  discovery, custom-order, order-square, my-orders, cart, messages, profile
  merchant:   dashboard, product-list, demand-market, qualifications, orders, my-shop, messages
  certifier:  review-list, review-history, qual-management, statistics, messages
  admin:      user-management, certifier-management, rule-management, content-audit, dispute, reports
  regulator:  archive-search, merchant-audit, product-spot, emergency, statistics
```

### 路由实现

```javascript
// vue-app.js — 动态挂载/卸载 Vue 页面组件
function navigateTo(pageKey) {
    currentPage.value = pageKey;
    nextTick(() => {
        var container = document.getElementById('legacy-page-container');
        if (VuePages[pageKey]) {
            // Vue 组件页面 → createApp + mount
            var pageApp = Vue.createApp({...});
            pageApp.component('vue-page-' + pageKey, VuePages[pageKey]);
            pageApp.mount(container);
        } else if (window.PageRenderers[pageKey]) {
            // 原生 JS 页面 → 直接渲染
            PageRenderers[pageKey](container, currentUser);
        }
    });
}
```

## 五、后端代码核心索引

### 启动流程 (`main.go`)

```
InitDB(dsn) → SeedDemoData() → PrintStats() → InitFabric() → Setup() → Run(":8080")
```

### ABE 服务层 (`service/abe_service.go`)

| 函数 | 作用 | 降级行为 |
|------|------|---------|
| `ConditionToPolicy(conds)` | 条件 Map → ABE 策略字符串 | — |
| `PolicyToDisplay(policy)` | 策略 → 用户可读中文 | — |
| `EncryptWithABE(text)` | 调 Java 加密 | 返回明文 |
| `DecryptWithABE(ct, attrs)` | 调 Java 解密 | 返回 error |
| `MatchAttributes(policy, attrs)` | 降级：字符串匹配 | — |
| `RevokeAttribute(type, val)` | 调 Java 撤销属性 | DB 标记 |
| `UpdateSystemKeys()` | 调 Java 密钥轮换 | 仅 DB 过期 |
| `ReEncryptContent(oldCT)` | 调 Java 重加密 | 保留旧密文 |

## 六、区块链集成

> ⚠️ Fabric 是可选组件。不可用时系统正常运行，仅追溯上链功能缺失。

### 架构

```
Go 后端 → Fabric Gateway SDK → Peer0.Org1 → traceability 链码 → 分布式账本
```

### 链码数据模型 (`chaincode/model/data_field.go`)

```go
type DataField struct {
    Id               string  // 记录 ID
    HashOfCiphertext string  // 密文哈希
    Origin           string  // 产地
    Status           string  // 状态
    AccessPolicy     string  // ABE 访问策略
}
```

### 链码操作

| 函数 | 类型 | 说明 |
|------|------|------|
| `CreateFruit(id, ciphertext, origin, status)` | 写 | 创建追溯记录 |
| `QueryFruit(id)` | 读 | 查询追溯记录 |

### 自动上链时机

创建加密需求时（`HandleCreateCustomOrder`），如果 `model.FabricReady == true`，自动调用 `SubmitToFabric()` 将密文哈希提交到 Fabric 账本。

### Fabric 连接配置

| 项 | 值 |
|----|-----|
| 网络 | `test-network` |
| 组织/MSP | `Org1` / `Org1MSP` |
| 通道 | `mychannel` |
| 链码 | `traceability` |
| 用户 | `User1@org1.example.com` |

### 降级

Fabric 不可用时 → `InitFabric()` 打印 `[WARN]` → `FabricReady = false` → 不影响任何核心功能。
