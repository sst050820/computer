# 农禾坊 — 文档阅读指南

## 这个项目是什么？

一句话：**消费者用 ABE 加密发布定制需求，只有持有匹配资质的商家才能解密查看**。技术核心是属性基加密（MAFASAC-AR）+ Hyperledger Fabric 区块链追溯。

---

### 路径 A：快速了解（15 分钟）

```
农禾坊-项目概述  →  部署运维与演示
```

读完能跑起来、用演示账号走一遍流程。

### 路径 B：深入 ABE 核心（30 分钟）

```
农禾坊-项目概述  →  ABE属性基加密详解
```

读完能理解 ABE 密码学原理、完整数据流、安全模型。

### 路径 C：全面掌握（60 分钟）

```
农禾坊-项目概述  →  系统架构全景  →  ABE属性基加密详解  →  角色-API-数据库  →  部署运维与演示
```

按这个顺序读完，就能理解整个项目的每一层。
